# AI 스마트 윈도우 – 포항의 내일을 여는 창

2035년 포항을 배경으로 AI 스마트 윈도우의 기능을 설명하는 사진 기반 모션그래픽 영상입니다. 한국어 합성 음성, 자막, 배경음악을 포함합니다.

[최신 영상 MP4 다운로드](https://github.com/wwplato/ai-video-project/raw/refs/heads/main/output/AI_Smart_Window_Pohang.mp4)

이번 수정본은 실내·인물 장면을 사진풍으로 새로 제작하고, 화면 전체를 사용하는 구도로 다시 편집했습니다. 침실, 학생의 유리 터치, 가족, 원격 제어 장면의 표현을 통일했습니다. 창문에 맞춘 차광·반투명 효과와 부드러운 화면 이동, 간결한 정보 표시를 적용했습니다.

창문 안내와 내레이터의 음색은 구분됩니다. 배경음악을 새로 구성하고, 대사가 나올 때 음악의 음량이 내려가도록 믹싱했습니다. 2035년 설정, 15장면, 2분 30초 길이를 유지합니다.
