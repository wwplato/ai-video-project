# 3D 애니메이션 원본

`scene.py`는 이 영상의 캐릭터, 실내, 포항 해안 도시와 움직임을 만드는 Blender Python 원본입니다. 외부 캐릭터나 인물 사진 없이 3D 메시와 관절 좌표로 구성합니다.

Blender 4.3.2에서 실행했습니다. 아래 명령은 6번 장면(학생의 창문 터치)의 10초를 24fps로 렌더링합니다. `--scene`은 0부터 14까지입니다.

```sh
blender -b --factory-startup --python production/scene.py -- --scene 5 --frames 240 --width 1280
```

결과 PNG는 `production/frames/05/`에, 움직임 좌표는 `production/motion_05.json`에 저장됩니다. `--test`는 주요 자세 6개만 렌더링하며, `--sample 144`는 6초 시점 한 프레임을 렌더링합니다.

움직임은 프레임마다 갱신됩니다. 캐릭터의 걷기·손 뻗기·기상·블록 옮기기·휴대폰 터치와 파도·차량·커튼·식물·창문을 함께 제어합니다. `textures/`는 3D 창문과 휴대폰에 표시하는 한국어 정보 화면입니다.

이 원본은 3D 장면 렌더링용입니다. 최종 MP4에는 별도로 합성한 한국어 자막과 기존 음성·음악이 포함됩니다.
