# AI 스마트 윈도우 – 포항의 내일을 여는 창

2035년 포항을 배경으로 AI 스마트 윈도우의 기능을 설명하는 모션그래픽 영상입니다. 한국어 합성 음성, 자막, 배경음악을 포함합니다.

[최신 영상 MP4 다운로드](https://github.com/wwplato/ai-video-project/raw/refs/heads/main/output/AI_Smart_Window_Pohang.mp4)

이번 수정본은 배경 연도를 2035년으로 변경하고, 낮·노을·밤·태풍 상황의 포항 배경을 새로 제작했습니다. 창틀과 정보 패널의 빛과 재질 표현을 개선했으며, 그래픽과 글자를 Full HD로 렌더링했습니다.
