# LUMINEX — 포항의 내일을 여는 창

2035년 포항의 인공지능 스마트 윈도우를 소개하는 3D 애니메이션입니다. 새 그래픽으로 본편 15장면, 150초를 출력하고 있습니다.

[새 그래픽 10초 미리보기 다운로드](output/LUMINEX_preview_10s.mp4)

피부·머리카락·의상 텍스처가 있는 Rocketbox 캐릭터와 실제 관절 동작, Wayfair의 가구 모델을 적용했습니다. 포항 해안 전망, 목재 바닥과 실내 조명을 새로 구성하고, 로고·창문 UI·소개 및 엔딩 음성을 LUMINEX(루미넥스)로 바꿨습니다. 한국어 내레이션과 별도 창문 안내 음성, 잔잔한 피아노 음악을 사용합니다.

전체 MP4는 렌더링·합성·디코딩 검증이 끝나면 `output/AI_Smart_Window_Pohang.mp4`에 반영합니다. 이 작업 중인 브랜치의 해당 파일은 아직 교체 전입니다.
